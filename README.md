# Tally

用柳比歇夫时间管理法记录每一天：开始计时、结束记录、查看当日时间分配，再按周、月或自定义区间回看时间去了哪里。

v0.10.0 更新桌面图标并让分析图更能读：今日饼图点击扇区会高亮下方对应活动，其他扇区淡化；周/月/自定义折线图在数据点旁直接标出学习+工作与全部活动的数值；启动页保持纯色背景，不显示自定义启动图。

> **下载最新版 APK**：[GitHub Releases](https://github.com/miaobianzhang/tally/releases/latest)

## 功能

- 单按钮开始/结束计时，时长由墙钟时间戳推导，切后台或杀进程不会丢失；开始/结束播放扩散环，运行中有呼吸光晕，按下有缩放与触感反馈。系统开启「减少动态效果」时自动收敛为颜色和触感。
- 计划页：底部新增「计划」Tab（计时 / 计划 / 分析）；周计划按周、月计划按月管理，可切换任意过去或未来周期；Deadline 精确到日期，按逾期/今天/未来着色，日期选中为黑色实心圆。
- 点击未完成的计划项目会预填活动名称和分类并开始计时；过渡从点击位置展开，以分类色光环和浅色幕布覆盖，随后切到计时页并淡出，计时按钮的启动光晕正好露出。计时保存后计划不会自动完成，需在计划页手动勾选。
- 计划页右上角「设置」可分别隐藏周计划、月计划、Deadline 区块，也可用数字 1/2/3 指定三个区块从上到下的顺序；隐藏与顺序相互独立，隐藏不会删除数据。
- 周期切换器：`‹ 日期 ›` 逐周/逐月切换，点中间打开选择周或选择月弹窗；弹窗右上角的「本周 / 本月」可一键回到当前周期；分析页禁用未来周期，计划页可排到未来 52 周或 24 个月。
- 结束后填写活动内容，并从六个分类中选择一个（工作 / 学习 / 休息 / 运动 / 生活 / 其他）。
- 记录弹窗打开输入法时整张底部面板随键盘上移，「活动内容」不会被遮挡；可拖动滚动到分类与保存按钮。
- 自动记住上次使用的分类。
- 今日分析：顶部显示今日总时间、学习+工作时间及占比；单环活动图的每个扇区都用引导线直接标出活动名，不再显示分类名；活动较多时图表自动加高，环形图不显示中心总计。
- 今日饼图可点击：选中扇区保持原色、其他扇区淡化，下方对应活动行同步高亮；再点一次取消，也可以直接点列表行选中，方便 TalkBack 使用。
- 今日时间轴：真实 0–24 点竖向刻度，左侧 48dp 窄色块按开始时刻落位、高度按持续时长比例；右侧两行显示活动名与起止时间/时长，标签重叠时上下错开并用细线连回色块，点击块或标签查看并编辑活动名称和分类；跨午夜记录会在所有相关日期同步更新。
- 独立周分析页：从今日分析页顶部「周分析」进入；可切换任意一周，依次显示本周统计、分类分布、有效时间趋势和按天分行的 24 小时时间轴，点击色块查看活动明细并修改名称和分类。
- 月分析：从今日分析页顶部「月分析」进入；可逐月切换或选择任意月份。本月统计到今天，选中过去的月份时显示完整自然月；内容包含区间概览、分类分布、时间分布堆叠柱状图和有效时间趋势。
- 周分析、月分析和自定义分析共用同一套分类分布环：大扇区在环带内直接显示分类名，小扇区用引导线在环外标注；下方图例继续给出分类时长与百分比。
- 自定义分析：从今日分析页顶部「自定义」进入；打开自定义区间选择器后，内容与月分析一致。
- 区间概览：总时间、学习+工作时间与占比、按已过天数计算的日均，进入页面第一屏即可看到。
- 分类分布饼图：按所选区间统计每个大类的时间占比，图例同时给出分类时长与百分比。
- 时间分布堆叠柱状图按分类着色，点击某一天/某一周可查看该时段的活动明细。
- 有效时间趋势图有两条线：学习+工作总时长为实线，全部活动为虚线；共用同一纵轴，并配实线/虚线图例。每个数据点旁标出两条线的数值（黑字为学习+工作，灰字为全部活动）；14 个点以内全部标注，更长区间只标约 7 个采样点，横向滚动时标签跟随。
- 图表按区间自适应：14 天以内按天，超过 14 天按周一至周日的自然周汇总；7 个日桶即使窄屏也完整显示周一至周日。
- 崩溃恢复：结束瞬间被杀进程，重开后仍会弹出记录窗口；重复保存不会产生重复记录。
- 跨午夜或跨区间边界的记录按实际重叠时间计入；时间轴会把跨午夜记录拆成两天。
- 仅浅色主题，无账号、无网络依赖。

## 环境要求

- Node.js 22.13+/24.3+/26（本项目在 Node 26 LTS 上开发）。
- 开发调试：Android 手机安装 **Expo Go**（需支持 Expo SDK 58），手机与电脑在同一 Wi-Fi。
- 独立安装：直接安装 EAS 构建的 APK，不需要 Expo Go。

## 安装到 Android 手机

应用通过 EAS 云端构建为独立 APK（包名 `com.tally.app`）。在手机浏览器打开构建产物的下载链接，允许“安装未知来源应用”后安装即可；安装完成后桌面会出现 Tally 图标。

从 GitHub Releases 下载最新 APK：

https://github.com/miaobianzhang/tally/releases/latest

当前 v0.10.0 APK：97,114,358 字节 / 92.62 MiB

SHA-256：`0F528826CD175A5B4209EEFCF02F20D7443328ED0656FBC16DAB2FA56CDFDBEB`

Release 附件由 GitHub 长期托管，下载不需要 GitHub 账号；EAS 的临时构建链接约 14 天后失效，不再作为主要下载渠道。

重新构建 APK：

```bash
npx eas-cli@latest build -p android --profile preview
```

项目尚未初始化 Git，构建前需设置 `EAS_NO_VCS=1`（PowerShell：`$env:EAS_NO_VCS = '1'`）。`preview` profile 输出可直接安装的 APK；每次重新构建前请递增 `app.json` 中的 `android.versionCode`，否则手机可能拒绝覆盖安装。签名密钥由 EAS 托管，请保留 `miaobianzhang` 账号的访问权限。

```text
    _layout.tsx              # 根 Stack + TallyProvider + 结束弹窗
    (tabs)/_layout.tsx       # 底部三个 tab

    weekly.tsx               # 周分析页

    custom.tsx               # 自定义区间分析页

  types.ts                   # Session / TimerState / PlanItem / PlanPrefs
```

## 数据

所有数据通过 AsyncStorage 保存在设备本地，键名前缀 `@tally/`：

- `@tally/sessions/v1`：已保存的时间记录。
- `@tally/timer/v1`：当前计时状态（idle / running / pending）。
- `@tally/prefs/v1`：上次使用的分类。
- `@tally/plans/v1`：周计划、月计划与 Deadline。
- `@tally/plan-prefs/v1`：三个计划区块的显示/隐藏设置与排列顺序（旧版本数据会自动补齐默认顺序，保留原有开关）。

卸载 App 或清除应用数据会删除记录。当前版本不提供云端同步与导出。
