# Tally

用柳比歇夫时间管理法记录每一天：开始计时、结束记录、查看当日时间分配，再按周、月或自定义区间回看时间去了哪里。

v0.14.0 把 Deadline 倒计时改成右侧大字，完成计划和分类排序加入平滑移动动画；月分析 7 天档位每天都有折线圆点，周分析新增固定的 7 天分类堆叠柱状图。上一版加入 Deadline 天数徽标、已完成计划一键删除、分类删除/排序和输入法避让。

> **下载最新版 APK**：[GitHub Releases](https://github.com/miaobianzhang/tally/releases/latest)

## 功能

- 单按钮开始/结束计时，时长由墙钟时间戳推导，切后台或杀进程不会丢失；开始/结束播放扩散环，运行中有呼吸光晕，按下有缩放与触感反馈。系统开启「减少动态效果」时自动收敛为颜色和触感。
- 计划页：底部新增「计划」Tab（计时 / 计划 / 分析）；周计划按周、月计划按月管理，可切换任意过去或未来周期；Deadline 精确到日期，按逾期/今天/未来着色，日期选中为黑色实心圆。
- 点击未完成的计划项目会预填活动名称和分类并开始计时；过渡从点击位置展开，以分类色光环和浅色幕布覆盖，随后切到计时页并淡出，计时按钮的启动光晕正好露出。计时保存后计划不会自动完成，需在计划页手动勾选。
- 计划页右上角「设置」可分别隐藏周计划、月计划、Deadline 区块，也可用数字 1/2/3 指定三个区块从上到下的顺序；隐藏与顺序相互独立，隐藏不会删除数据。
- 周期切换器：`‹ 日期 ›` 逐周/逐月切换，点中间打开选择周或选择月弹窗；弹窗右上角的「本周 / 本月」可一键回到当前周期；分析页禁用未来周期，计划页可排到未来 52 周或 24 个月。
- Deadline 的每一项在右侧显示大字倒计时：`N 天`、`今天截止`、`逾期 N 天` 或 `已完成`，不加外框；已完成项目提供一键删除按钮。
- 勾选完成计划时，复选框会弹跳、勾号缩放淡入，并扩散一圈分类强调色光环；项目同时平滑移动到已完成区域末尾。系统开启「减少动态效果」时自动省略动画。
- 首页左上角头像进入设置页；可修改头像、用户名，管理分类、外观、数据和可选云同步。头像和背景上传后会持久保存，重新进入 App 仍会显示；新头像会替换旧头像。修改用户名时，个人资料面板会随输入法上移，避免输入框被遮挡。
- 头像裁剪支持双指缩放和单指拖动，并显示圆形取景框；背景裁剪使用矩形取景框，可调图片不透明度，切换预设时已上传的相册背景会保留。
- 分类可新增、改名、改色、停用、恢复和删除，并用 ↑ / ↓ 调整顺序；排序时行位置带移动动画，停用和删除都会保留历史记录，内置六类也可以停用或删除；每个分类可标记「计入专注统计」，用于趋势图的实线。
- 结束后填写活动内容，并从当前可用分类中选择一个；默认带有工作 / 学习 / 休息 / 运动 / 生活 / 其他六类。
- 记录弹窗打开输入法时整张底部面板随键盘上移，「活动内容」不会被遮挡；可拖动滚动到分类与保存按钮。
- 自动记住上次使用的分类。
- 今日分析：顶部显示今日总时间、学习+工作时间及占比；单环活动图的每个扇区都用引导线直接标出活动名，不再显示分类名；活动较多时图表自动加高，环形图不显示中心总计。
- 今日饼图可点击：选中扇区保持原色、其他扇区淡化，下方对应活动行同步高亮；再点一次取消，也可以直接点列表行选中，方便 TalkBack 使用。
- 今日时间轴：真实 0–24 点竖向刻度，左侧 48dp 窄色块按开始时刻落位、高度按持续时长比例；右侧两行显示活动名与起止时间/时长，标签重叠时上下错开并用细线连回色块，点击块或标签查看并编辑活动名称和分类；跨午夜记录会在所有相关日期同步更新。
- 独立周分析页：从今日分析页顶部「周分析」进入；可切换任意一周，依次显示本周统计、分类分布、固定的 7 天分类堆叠柱状图、有效时间趋势和按天分行的 24 小时时间轴，点击色块查看活动明细并修改名称和分类。柱状图直接铺满宽度，不需要横向滑动。
- 月分析：从今日分析页顶部「月分析」进入；可逐月切换或选择任意月份。本月统计到今天，选中过去的月份时显示完整自然月；内容包含区间概览、分类分布、每日时间分布和有效时间趋势。
- 周分析、月分析和自定义分析共用同一套分类分布环：大扇区在环带内直接显示分类名，小扇区用引导线在环外标注；下方图例继续给出分类时长与百分比。
- 自定义分析：从今日分析页顶部「自定义」进入；打开自定义区间选择器后，内容与月分析一致。
- 区间概览：总时间、学习+工作时间与占比、按已过天数计算的日均，进入页面第一屏即可看到。
- 分类分布饼图：按所选区间统计每个大类的时间占比，图例同时给出分类时长与百分比。
- 月分析和自定义分析始终按天显示；时间分布和有效时间趋势放在同一张卡片、共享横向滚动和日期刻度。月分析提供 7/14/30 天档位，自定义分析额外提供 90 天；切到 7 天档位时，趋势折线会为每个可见日期显示圆点。支持回到最新，长区间只渲染可视窗口，避免五千天数据卡顿。
- 每日柱状图按分类着色，点击任意一天可查看该日明细；趋势图实线为「计入专注统计」的分类合计，虚线为全部活动，图例随分类配置变化。
- 外观：跟随系统 / 浅色 / 深色；可自定义页面背景、卡片背景、按钮强调色，文字和边框自动保证可读性；自定义颜色支持 2D 饱和度/亮度色板 + 色相滑杆。首页支持 3 套渐变背景或从相册选择照片，选中背景有描边和勾选标记。
- 数据：导出记录、计划、分类与偏好的 JSON 备份或 CSV 记录表，导入 JSON 时按记录合并；同步与导出都不会包含头像/背景照片。导出的文件是明文，请妥善保存。
- 可选云同步：使用坚果云 WebDAV 和独立同步密码，数据在应用内用 PBKDF2 + AES-256-GCM 加密后上传；不配置同步时 App 仍完全离线可用。
- 崩溃恢复：结束瞬间被杀进程，重开后仍会弹出记录窗口；重复保存不会产生重复记录。
- 跨午夜或跨区间边界的记录按实际重叠时间计入；时间轴会把跨午夜记录拆成两天。

应用通过 EAS 构建为独立 APK（包名 `com.tally.app`）。在手机浏览器打开下载链接，允许“安装未知来源应用”后安装即可；安装完成后桌面会出现 Tally 图标。

从 GitHub Releases 下载最新 APK：

https://github.com/miaobianzhang/tally/releases/latest

最新 APK（v0.14.0）：98,621,500 字节 / 94.05 MiB

SHA-256：`616B6F15A236F45CDEFACCC577FFB249C15954FA27E02B2BC97E79ACCA98057B`

构建记录：https://github.com/miaobianzhang/tally/actions/runs/45197114612

Release 附件由 GitHub 长期托管，下载不需要 GitHub 账号。本版 APK 通过 GitHub Actions 在 Ubuntu runner 上执行 `eas build --local` 构建，使用原有 EAS 托管签名证书，不消耗 EAS 云端构建额度。

重新构建 APK：

```bash
# 方式一：GitHub Actions 本地构建（不占 EAS 云额度）
gh workflow run android-preview.yml --ref main -R miaobianzhang/tally

# 方式二：EAS 云端构建（会消耗当月免费构建额度）
EAS_NO_VCS=1 npx eas-cli@latest build -p android --profile preview
```

GitHub Actions 方式需要先把 Expo access token 写入仓库 Secret `EXPO_TOKEN`；构建结束后可撤销 token 并删除 Secret。方式二的 `preview` profile 输出可直接安装的 APK。每次重新构建前请递增 `app.json` 中的 `android.versionCode`，否则手机可能拒绝覆盖安装。签名密钥由 EAS 托管，请保留 `miaobianzhang` 账号的访问权限。

## 可选云同步（坚果云 WebDAV）

同步不是必填项。需要多设备时，在「设置 → 数据 → 云同步（可选）」中填写（没有账号可先[注册坚果云](https://www.jianguoyun.com/#/register)）：

- WebDAV 地址：`https://dav.jianguoyun.com/dav/`
- 坚果云注册邮箱
- 坚果云「账户信息 → 安全选项 → 第三方应用管理」生成的 16 位应用密码
- 一个至少 8 位的 Tally 同步密码（用于加密，忘记无法恢复）

数据保存在 WebDAV 的 `Tally/tally-sync.json`，上传前会用 PBKDF2-SHA256 + AES-256-GCM 加密。同步入口保持低调，不配置时 App 不会发起任何网络请求。

## 数据

所有数据通过 AsyncStorage 保存在设备本地，键名前缀 `@tally/`：

- `@tally/sessions/v1`：已保存的时间记录。
- `@tally/timer/v1`：当前计时状态（idle / running / pending）。
- `@tally/prefs/v1`：上次使用的分类。
- `@tally/plans/v1`：周计划、月计划与 Deadline。
- `@tally/plan-prefs/v1`：三个计划区块的显示/隐藏设置与排列顺序（旧版本数据会自动补齐默认顺序，保留原有开关）。
- `@tally/categories/v1`：分类名称、颜色、顺序、停用/删除状态与「计入专注统计」标记。
- `@tally/user-prefs/v1`：主题模式、页面/卡片/按钮颜色与首页背景。
- `@tally/profile/v1`：本机用户名与头像文件路径。
- `@tally/tombstones/v1`：已删除计划的同步墓碑。
- `@tally/sync-config/v1`：可选的坚果云 WebDAV 地址、账号、路径与同步状态。

WebDAV 应用密码和同步密钥单独存放在系统安全存储（SecureStore），不写入普通 AsyncStorage，也不会导出。头像和背景照片保存在 App 文档目录，不参与同步。

卸载 App 或清除应用数据会删除本机记录。开启同步后，云端保留加密副本；忘记同步密码将无法解密云端数据。
